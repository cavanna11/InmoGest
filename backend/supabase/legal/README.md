Versiones de términos y política de privacidad que se publican en la base (ADR 0009). Cada carpeta es una versión inmutable: para cambiar un texto ya publicado, se crea una versión nueva.

|---|---|
| `beta-1` | Beta cerrada (ADR 0010). Publicada el 03/11/2026 con `npm run beta -- legal beta-1`. **Sin revisión profesional:** revisar antes del lanzamiento comercial (PRD §10). |
