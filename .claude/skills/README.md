# Skills de Claude Code

Las skills exclusivas del proyecto pueden ubicarse en subcarpetas de este directorio siguiendo la estructura vigente de Claude Code.

```text
.claude/skills/
└── nombre-skill/
    ├── SKILL.md
    ├── references/   # opcional
    └── scripts/      # opcional
```

Verificar siempre la documentación oficial antes de crear o migrar una skill.
