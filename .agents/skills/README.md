# Skills de OpenAI Codex

Las skills específicas del repositorio pueden ubicarse aquí:

```text
.agents/skills/
└── nombre-skill/
    ├── SKILL.md
    ├── scripts/      # opcional
    ├── references/   # opcional
    └── assets/       # opcional
```

Codex descubre skills de repositorio en `.agents/skills` desde el directorio de trabajo hasta la raíz del repo. Verificar la documentación oficial vigente antes de adoptar campos opcionales o políticas de invocación.
